# إشعارات الهاتف لانتهاء المؤقتات — دليل التفعيل (CODIS 3.11.0)

## شنو يشتغل هسه بدون أي إعداد

- **المؤقت نفسه** (مكافأة «ساعة سوشل ميديا» أو مهمة «تمرين 10 دقايق») يُحفظ بوقت نهاية مطلق، فما يرجع للبداية ولا يوكف لو سكّرت التطبيق أو انتقلت لغيره. لما ترجع تفتح التطبيق يكمّل من الوقت الصحيح، وإذا خلص وانت برا يُسجَّل كمنتهي فوراً.
- **إشعار الجهاز** يوصل عبر Service Worker ما دام التطبيق مفتوحاً أو بالخلفية والصفحة بعدها حيّة. يحتاج تفعيل «إشعارات المتصفح» من الإعدادات.

## شنو يحتاج إعداد الخادم

**الإشعار بعد إغلاق التطبيق بالكامل.** المتصفح يوكف JavaScript لما يتسكّر التطبيق، فلازم الخادم هو اللي يرسل الإشعار بالوقت. الملفات جاهزة بالمستودع، بس تحتاج حسابك على Supabase:

| الملف | الوظيفة |
|---|---|
| `sql/codis_push.sql` | جدولا اشتراكات الأجهزة والمؤقتات المجدولة، والدوال الآمنة (RLS) |
| `supabase/functions/codis-push/index.ts` | الدالة اللي ترسل Web Push |
| `sw.js` | يستقبل الإشعار على الجهاز ويفتح التطبيق عند الضغط عليه |

> ⚠️ **الأسرار:** المفتاح الخاص VAPID ومفتاح service_role يُحفظان بأسرار Supabase فقط. لا تحطهم بأي ملف ولا ترفعهم لـ GitHub. اللي يروح للصفحة هو المفتاح **العام** بس.

## الخطوات (مرة وحدة)

### 1) قاعدة البيانات
Supabase → SQL Editor → الصق محتوى `sql/codis_push.sql` واضغط Run. آمن تشغيله أكثر من مرة.

### 2) مفاتيح VAPID
على جهازك (يحتاج Node.js):
```bash
npx web-push generate-vapid-keys
```
يطلعلك **Public Key** و **Private Key**.

### 3) المفتاح العام بالصفحة
بـ `index.html` (و `app/CODIS_FINAL.html`) غيّر السطر:
```html
<meta name="codis-vapid-public-key" content="">
```
وحط المفتاح **العام** بين علامتي التنصيص. هذا المفتاح عام بطبيعته.

### 4) أسرار الدالة
Supabase → Edge Functions → Secrets، وضيف:
- `VAPID_PUBLIC_KEY` = المفتاح العام
- `VAPID_PRIVATE_KEY` = المفتاح الخاص
- `VAPID_SUBJECT` = `mailto:` وبعده إيميلك
- `CODIS_CRON_SECRET` = نص عشوائي طويل، تولّده بهذا الأمر:
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### 5) نشر الدالة
**من لوحة Supabase:** Edge Functions → Deploy a new function → الاسم `codis-push` → الصق محتوى `supabase/functions/codis-push/index.ts` → **أطفئ «Enforce JWT verification»**. الحماية هنا بالسر `CODIS_CRON_SECRET`.

**أو من سطر الأوامر:**
```bash
supabase functions deploy codis-push --no-verify-jwt --project-ref hkrqiqzkkjmokjabovpq
```

### 6) الجدولة كل دقيقة
1. Database → Extensions → فعّل `pg_cron` و `pg_net`.
2. SQL Editor → خزّن السرّين بالخزنة (Vault). بالسطر الثاني حط نفس قيمة `CODIS_CRON_SECRET`:
```sql
select vault.create_secret('https://hkrqiqzkkjmokjabovpq.supabase.co/functions/v1/codis-push', 'codis_push_url');
select vault.create_secret('<نفس قيمة CODIS_CRON_SECRET>', 'codis_push_cron_secret');
```
3. شغّل الكتلة الموجودة بالقسم 5 بآخر `sql/codis_push.sql`، بعد ما تشيل علامات `--` من بداية أسطرها.

### 7) على الهاتف
- **آيفون:** افتح الموقع من Safari → مشاركة → «إضافة إلى الشاشة الرئيسية» → افتح CODIS من الأيقونة. يحتاج iOS 16.4 أو أحدث.
- **أندرويد:** Chrome يكفي، والتثبيت مستحسن.
- سجّل الدخول بحسابك، وبعدها: الإعدادات → الإشعارات → «إشعارات المتصفح» → اسمح. هنا يسجّل الجهاز اشتراكه.

### 8) التجربة
1. أضف مهمة «تمرين 2 دقايق» واضغط «ابدأ المهمة».
2. سكّر التطبيق بالكامل.
3. بعد دقيقتين (+ دقيقة كحد أقصى لدورة الجدولة) يوصلك: «انتهى الوقت المحدد لمهمة تمرين».

## منع التكرار

- كل انتهاء مؤقت له معرّف حدث فريد (`ev_…`).
- الخادم يحجز الحدث مرة وحدة بس (`push_claim_due`)، فتكرار تشغيل الجدولة ما يرسل مرتين.
- إذا خلص المؤقت والتطبيق مفتوح، الصفحة تعرض الإشعار وتلغي الإرسال من الخادم (`push_cancel`).
- إشعار الصفحة وإشعار الخادم يحملان نفس الوسم (`tag`)، فلو تصادفا بنفس اللحظة النظام يستبدل الواحد بالثاني بدل ما يعرضهم مرتين.
- سجل الإشعارات داخل CODIS يحفظ الحدث مرة وحدة (`uniqueKey`).
