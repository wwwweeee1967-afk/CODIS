# إشعارات المؤقتات والتطبيق مسكّر — التفعيل (CODIS 3.13.0)

الإشعار بعد إغلاق التطبيق لازم يرسله الخادم، لأن الجهاز يوقف الصفحة لما تتسكّر.

**ما تحتاج أي مفتاح سري:**
- مفاتيح VAPID يولّدها الخادم نفسه بأول تشغيل، ويحفظها بخزنة Supabase (Vault).
- الصفحة تجيب المفتاح العام بس، من الخادم تلقائياً.
- سرّ الجدولة يتولّد داخل قاعدة البيانات.

## الخطوات (مرة وحدة)

### 1) انشر الدالة
Supabase → Edge Functions → **Deploy a new function**:
1. الاسم: `codis-push`
2. الصق محتوى `supabase/functions/codis-push/index.ts`
3. **أطفئ «Verify JWT»**. الحماية بسرّ الجدولة.

أو من سطر الأوامر:
```bash
supabase functions deploy codis-push --no-verify-jwt --project-ref hkrqiqzkkjmokjabovpq
```

### 2) شغّل ملف SQL واحد
Supabase → SQL Editor → الصق محتوى `sql/codis_push.sql` كاملاً → **Run**.

هذا الملف:
- ينشئ الجداول والدوال.
- يفعّل `pg_cron` و`pg_net`.
- يولّد سرّ الجدولة.
- يجدول الإرسال كل دقيقة.
- يشغّل الدالة أول مرة حتى تولّد المفاتيح.

تشغيله أكثر من مرة آمن. لو ظهر خطأ بسطر `create extension`، فعّل `pg_cron` و`pg_net` من Database → Extensions وأعد التشغيل.

## على الهاتف
- **آيفون:** افتح الموقع من Safari → مشاركة → «إضافة إلى الشاشة الرئيسية» → افتح CODIS من الأيقونة. يحتاج iOS 16.4 أو أحدث.
- سجّل الدخول، وبعدها: الإعدادات → الإشعارات → «إشعارات المتصفح» → اسمح.
- الأجهزة اللي فعّلت الإشعارات من قبل تتسجّل تلقائياً بأول فتح بعد التحديث.

## التجربة
1. أضف مهمة «تمرين 2 دقايق» واضغط «ابدأ المهمة».
2. سكّر التطبيق بالكامل.
3. بعد دقيقتين، ودقيقة كحد أقصى لدورة الجدولة، يوصلك: «انتهى الوقت المحدد لمهمة تمرين».

## الفحص لو ما وصل
- **SQL Editor:**
  - هل المفتاح العام موجود؟ `select public.push_vapid_public();` لازم يرجع نص طويل.
  - هل الجهاز مسجّل؟ `select count(*) from push_subscriptions;`
  - المؤقتات وحالتها: `select event_id, fire_at, sent_at, cancelled_at from push_timers order by created_at desc limit 5;`
  - نتائج الجدولة: `select status_code, content from net._http_response order by created desc limit 5;`
    - الحالة الصحيحة 200 ونص مثل `{"claimed":…,"sent":…}`.
    - 403 يعني الدالة منشورة مع «Verify JWT» شغّال.
- **Edge Functions → codis-push → Logs:** أخطاء الإرسال.

## منع التكرار
- كل انتهاء مؤقت له معرّف حدث فريد (`ev_…`)، والخادم يحجزه مرة وحدة (`push_claim_due`).
- إذا خلص المؤقت والتطبيق مفتوح، الصفحة تعرض الإشعار وتلغي إرسال الخادم (`push_cancel`).
