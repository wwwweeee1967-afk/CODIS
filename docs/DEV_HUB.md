## CodisClock
`CodisClock.now/date/iso/day/key` = وقت العمل. الإزاحة 0 للجميع. `begin()` ترفض غير الموثَّق (`CodisAccount.isAdmin`، قرار الخادم). `shiftDays(n)` تقويمي (لا يتأثر بالتوقيت الصيفي)، `setDay('YYYY-MM-DD')` يرفض التواريخ المستحيلة. لا تُحفظ الإزاحة في أي تخزين ⇒ إعادة التحميل = خروج. لا تبديل لـ`Date`/`Date.now`.
**قاعدة**: أي منطق جديد يعتمد «اليوم/الأسبوع/الشهر/انتهاء صلاحية» يقرأ من `CodisClock`؛ والجلسة/المزامنة/الحركة/الإشعارات الفعلية تبقى `Date.now()`.

## مختبر الزمن
نسخة عمل = نسخة عميقة من `data` داخل عزل المعاينة (تخزين وهمي + `CODIS_SYNC_HOLD`). كل يوم: `shiftDays(1)` ← `codisCheckDayChange` (أرشفة الخطط المنتهية + الشهر + العادات + إعادة رسم الغرف) ← `runHabitChecks` ← `econTick` ← `CodisTimers.tick` ← `hcdTick`. ثم مقارنة قبل/بعد تُسجَّل (نتائج أسبوعية/شهرية/عادات/إشعارات/رصيد). الإنهاء: `endIso` يعيد كائن `data` الأصلي، ثم مقارنة JSON كاملة قبل إعلان نجاح الاستعادة. نقطة استعادة على الجهاز (`codis_timelab_restore_v1`) + علَم انقطاع (`codis_timelab_flag_v1`). **حدود**: الرجوع للخلف غير مدعوم؛ الحد 1500 يوم بالمرة؛ المؤقتات المحلية تتبع الساعة المنطقية لكن الإشعارات الفعلية معطّلة؛ نوافذ النتائج الطبيعية تظهر كما في الاستعمال العادي.
