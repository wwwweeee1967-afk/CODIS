# CODIS 3.5.0 — خريطة الصوت (CODIS-AUDIO-V2)

المصدر: `tools/patch_v11.py`. كل الأصوات مولّدة وقت التشغيل عبر Web Audio؛ لا ملفات صوت، لأن البيئة ما فيها أداة لتوليد أو تسجيل الصوت.
التسمية `اسم@سياق`. السياق يُمرَّر من موضع الاستدعاء (`codisSfx('open', { ctx:'store' })`). إذا ما في هوية للسياق، يرجع الصوت لهوية العائلة عن قصد.

## المحرك
| الجزء | ما تغيّر |
|---|---|
| النواقل | ناقل لكل قناة (ui/xp/reward/discipline) تحت master + محدِّد الصوت. مستوى القناة على الناقل. الخفض (`duck`) يخفّض ui/xp إلى 42% وقت الأحداث الكبرى ثم يرجّعها |
| الستيريو | `StereoPanner` لكل صوت (`pan`/`panTo`) |
| أدوات التوليد | `strike(مادة)`: رنين مادي بنسب غير توافقية للخشب والمجوّف والزجاج والمعدن والفضة والذهب والحجر والبلاستيك والبرونز والكريستال والحديد · `fm` · `grains` (قلم، ورق، عملات، شرار) · `air` (هواء) |
| التنويع | `vars` بدائل بلا تكرار متتالٍ + `jit` انحراف نغمي محدود |
| الأولويات | `cooldown` و`hold` لكل `key` · سقف 16 صوتاً مع سرقة الأقدم الأقل أهمية بتلاشٍ 40ms · حدّ أربع نسخ متزامنة من نفس الصوت · `seq` لطبقات الفعل الواحد |
| التشخيص | `CodisAudio.trace()` (آخر 60 حدثاً) · `events()` · `def(k)` · `render(name, opts, secs)` للتصيير داخل `OfflineAudioContext` |

## صمت مقصود
- ارتداد السحب للرجوع.
- النقرات على البطاقات أثناء الفتح.
- الحركات الزخرفية المتكررة (توهّج، نبض، تحريك الخلفية).
- تمرير القوائم.
- التنقّل الداخلي داخل الإعدادات، لأن زر الرجوع نفسه له صوت `close@settings`.

## ما بقي كما هو
- هويات الكروت الـ15 (CS) ونظام العقوبات (PN) وجدولتهما المتزامنة مع الأنيميشن بقيت، وانضافت فوقها طبقة توقيع للعائلة.
- عدّاد XP (`xp.*`) بقي بتسلسله المتزامن مع حركة الشريط.
- خمسة استدعاءات عامة بلا سياق (`invalid` ×4 و`confirm` ×1) في دوال قليلة الاستعمال.
