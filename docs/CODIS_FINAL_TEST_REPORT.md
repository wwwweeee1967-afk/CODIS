## 2. ما تغيّر في هذه الجولة
- `app/CODIS_FINAL.html`: نسخة مطابقة من الملف الحالي (لا تعديل على التطبيق).
- `tests/syntax.js`: صار يأخذ الملفات كوسائط، ومساراته الافتراضية نسبية للمشروع بدل `/mnt/...` و`/home/claude/...`، ويُرجع رمز خروج ≠ 0 عند الخطأ. الفحص نفسه لم يتغيّر.
- `tests/harness.js`: المسارات نسبية للمشروع؛ يدعم `CODIS_PSQL_MODULE` (جسر PGlite)؛ SQL يُمرَّر عبر stdin بدل `/tmp/q.sql`؛ يدعم `CODIS_PG_CONTAINER=<اسم حاوية PostgreSQL 16>` (Docker) بجانب `su postgres` الافتراضي في Linux. **لم يُغيَّر أي فحص أو شرط نجاح.**
- `tests/pglite_bridge.js` و`tests/run_sqltest.js`: جديدان، لتشغيل الاختبارات على PGlite. `tests/js_test_results.json` و`tests/sql_test_results.txt` أُعيد توليدهما من هذا التشغيل.
- `sql/codis_supabase_setup.sql`: **بلا تغيير**. طابقته يدوياً مع ما يستدعيه التطبيق:
  - `GET /rest/v1/progress?select=data,version,updated_at&user_id=eq.…` ⇐ جدول `progress(user_id, data, version, updated_at)` + سياسة قراءة الصف الخاص.
  - `POST /rest/v1/rpc/save_progress {p_data, p_base_version}` ⇐ الدالة `save_progress(jsonb, bigint)` وتُرجع `{ok, version}` أو `{ok:false, conflict:true, version, data, updated_at}`.
  - `POST /rest/v1/rpc/delete_my_account` ⇐ `delete_my_account()`.
  - `GET /rest/v1/admins?select=user_id` ⇐ جدول `admins(user_id)` + RLS.
  - `GET /storage/v1/object/authenticated/dev-addon/dev-addon.js` ⇐ bucket خاص `dev-addon` + سياسة قراءة للأدمن.
  - Auth: `/auth/v1/settings`، `/authorize?provider=google&flow_type=pkce`، `/token?grant_type=pkce|refresh_token`، `/logout?scope=local` (خدمات Supabase المدمجة، لا تحتاج SQL).

**بيئة PostgreSQL:** الجهاز بلا PostgreSQL، وDocker لا يعمل بدون WSL. لذلك استُخدم PGlite 0.2.17 (محرّك PostgreSQL 16.4 الحقيقي مترجماً إلى WebAssembly)، ثُبّت في مجلد مؤقت خارج المشروع بموافقة المستخدم. الجسر `tests/pglite_bridge.js` يحاكي خيارات psql التي تستخدمها الاختبارات فقط، وكل استدعاء جلسة جديدة (`reset role` + `discard all`). القيود: محرّك داخل العملية بمستخدم واحد، فلا تُختبر الأقفال بين اتصالات متزامنة حقيقية.

التشغيل:
```
NODE_PATH=<مجلد node_modules فيه @electric-sql/pglite@0.2.17> CODIS_PSQL_MODULE=tests/pglite_bridge.js node tests/harness.js
NODE_PATH=<نفس المجلد> node tests/run_sqltest.js
```
(على Linux مع PostgreSQL 16 يعمل `node tests/harness.js` كما كان؛ ومع Docker: `CODIS_PG_CONTAINER=<اسم الحاوية>`.)

### ما تغيّر
- **الرسومات:** الخمسة (1024² PNG شفافة) محفوظة بلا تعديل في `assets/box_art_original/`. نُسخ WebP مقصوصة على حدود كل صندوق (alpha محفوظ، 52–86 كيلوبايت) مدمجة في الملف (الملف الواحد صار ~8.6 ميغا). مصدر واحد `CODIS_BOX_ART` + `econBoxArt()` يحل محل رسم SVG القديم في كل المواضع (المتجر، بحوزتك، تفاصيل البكج، نافذة الشراء، الفتح، ×10). أبعاد كل صورة تختلف فعُدّل عرضها (`wf`) لتتقارب المساحة المرئية بلا تشويه.
- **المجسّم والفتح:** الرسم يُقسَم عند خط غطائه (مائل بحسب منظور كل صندوق) إلى جسم + غطاء داخل منظور CSS 3D؛ الغطاء يدور حول الدرزة، وقالب ضوء بشكل الغطاء (mask) يملأ الفتحة، وعمود ضوء وجسيمات Canvas. شاشة الجاهزية: صندوق مغلق يميل بالمس/الفأرة. شخصية مستقلة لكل مستوى (لون الضوء، شدة الاهتزاز 0.9→1.75، مدة الترقّب 640→1260ms، رفع الغطاء، نوع الجسيمات: غبار/شظايا/كريستال/جمر/هالة، مدار كاميرا للكريستالي والأسطوري). بلا مكتبة 3D خارجية.
- **استُبدل:** وحدة `CodisBoxCinema` القديمة كاملة (~450 سطراً) وكل CSS الحركة الخاصة بها (`.bxc-*`, `.bxr-*`, `.bx-lid`, `bxShake`…) وزر «الفتح: مختصر/كامل». لم يُمسّ `CodisMotion` ولا باقي أنيميشن التطبيق. `CodisRevealLevels` (تسعة مستويات من القيمة الفعلية للجائزة) بقي المصدر الوحيد لشدة الكشف ولم يُنشأ نظام ندرة ثانٍ.
- **الكشف:** خمس مجموعات بصرية (مستويات 1–2 · 3–4 · 5–6 · 7–8 · 9): ضوء/حلقات/عمود/وميض/اهتزاز/جسيمات/رونية، تأخير «تعليق» يطول مع المستوى، توهّج إطار البطاقة بلون المستوى. مسارات العرض المتخصصة (مكافأة، بطاقة تجاوز، عطلة، كيس فضة، مظهر) محفوظة كما هي.
- **×10:** عرض مختلف عن الفردي: عشرة صناديق مصغّرة على شبكة 5×2 تدخل بتتابع ثم تُفتح بالتتابع، ترتيب الكشف تصاعدي بمستوى القيمة (الأفضل أخيراً) وانفجار ولون أقوى للعالية، رقم الصندوق على كل خلية، «الأفضل» مميّزة وسطر «أفضل جائزة»، شريط تقدّم، تخطّي. الحركة CSS + مؤقّت إنهاء واحد + مؤقّتات صوت (≤3) تُمسح عند الإغلاق. `econBuyBox10` و`CodisBoxes.buyOpenMany` لم تتغيّرا.
- **الأهلية (الاقتصاد):** `CodisBoxes.MIN_VALUE = { bx1:0, bx2:50, bx3:90, bx4:165, bx5:245 }` (شامل >=). الحقل: `valueOf(x)` — نفس الحقل الذي يصنّف به المحرك الجوائز أصلاً (قيمة الاستبدال بالكوين للمكافأة؛ سعر بطاقة التجاوز/العطلة/الكيس/المظهر)، لا سعر المتجر. يُطبَّق داخل `classes(minV)` قبل تجميع الفئات، فتتبعه `effective()` ← الاحتمالات المعروضة والمسحوبة (نفس الدالة) ← التوفّر ← `stats()`. لم تُغيَّر أسعار الصناديق ولا خوارزمية الاحتمالات. تفاصيل البكج تعرض «قيمة كل كرت N كوين فأكثر».
